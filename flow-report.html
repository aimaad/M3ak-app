M3ak — Rapport d'audit des parcours utilisateur

29 octobre 2026 · Audit de l'application mobile et de la version web PC (lecture du code et captures d'écran avec données de démonstration ; pas de test sur de vrais utilisateurs)

flow-onboarding flow-forms flow-navigation flow-errors

Résumé

M3ak a de bonnes bases : navigation à 5 onglets avec libellés, assistant de réservation en étapes avec récapitulatif avant validation, écran d'accès expiré qui rassure sur les données, messages d'erreur traduits sans jargon technique. Les trois points faibles les plus importants sont (1) aucune aide au démarrage : un nouveau client arrive sur un tableau de bord vide, sans liste d'étapes ni action guidée ; (2) le message d'erreur générique « Un problème est survenu » masque la vraie cause (c'est lui qui nous a fait perdre du temps avec l'envoi d'e-mails et le code d'invitation) ; (3) des fonctions clés difficiles à trouver sur mobile (Chat M3ak, Contrats). Cet audit ne mesure aucun chiffre d'usage : les verdicts viennent du code et des guides appliqués.

Parcours : Premier lancement d'un nouveau client

Source des critères : flow-onboarding · Point d'entrée : le client reçoit un lien Expo / Netlify, un e-mail et un code d'invitation de la part de M3ak

Étapes

  1. 1Création du compte (inscription)

    E-mail, mot de passe, prénom et nom, puis code de confirmation reçu par e-mail.

    Action principale : Créer mon compte → saisie du code de confirmation

    Si l'envoi de l'e-mail échoue → message générique « Un problème est survenu » (cause invisible pour le client).
  2. 2Choix de l'agence : code d'invitation

    Un seul champ, le code donné par M3ak. Prénom et nom redemandés seulement s'ils manquent. Plus de création d'agence côté client.

    Action principale : Rejoindre l'agence → Accueil

    Si le code est refusé ou expiré → message d'erreur (seuls les cas connus sont expliqués).
  3. 3Accueil (tableau de bord)

    Bandeau de période d'essai (si applicable), carte « Demander à M3ak », indicateurs financiers. Pour une agence neuve : tout à zéro, aucune étape guidée.

    Action principale : aucune action de démarrage proposée → le client doit deviner par où commencer

Parcours : Saisie d'un client et création d'une location

Source des critères : flow-forms · Point d'entrée : onglets Clients puis Locations

Étapes

  1. 1Nouveau client (formulaire)

    Scan optionnel du permis et de la CIN, champs identité, documents, enregistrement. Les photos sont réduites et envoyées en parallèle.

    Action principale : Enregistrer → fiche client

    Si l'envoi d'un document échoue → fenêtre d'alerte, la fiche reste créée.
  2. 2Assistant de réservation (Client, Dates, Voiture, Conducteurs, Prix, Récapitulatif)

    Une étape par sujet, indicateur « Étape x sur y », bouton Précédent, calendrier, voitures libres seulement, ventilation du prix.

    Action principale : Suivant → récapitulatif

  3. 3Récapitulatif avant validation

    Toutes les réponses en lecture seule + total, puis deux boutons : enregistrer comme confirmée ou comme en attente.

    Action principale : Enregistrer comme confirmée → fiche de la location

Parcours : Navigation dans l'app

Source des critères : flow-navigation · Point d'entrée : barre du bas (mobile) ou menu latéral (web PC)

Étapes

  1. 1Barre du bas (mobile) : Accueil, Flotte, Clients, Locations, Équipe

    5 onglets avec icône et libellé, onglet actif marqué.

    Action principale : changer d'onglet → écran racine de l'onglet

  2. 2Fonctions « cachées » : Contrats, Chat M3ak, Maintenance, Notifications, Traçabilité, Mon entreprise, Profil

    Accessibles par des liens dans d'autres écrans (carte « Demander à M3ak » sur l'accueil, lien « Contrats » sur Locations, etc.).

    Action principale : lien contextuel → écran concerné

  3. 3Web PC : menu latéral à gauche, tableaux et impression

    Menu avec toutes les sections, filtré selon le rôle ; tableaux avec export CSV.

    Action principale : choisir une section → page de la section

Parcours : Erreurs et récupération

Source des critères : flow-errors · Point d'entrée : toute action qui échoue (réseau, e-mail, droits, accès expiré)

Étapes

  1. 1Une action échoue

    Le texte de l'erreur est traduit en message lisible (réseau, trop de tentatives, droits, déjà inscrit, mot de passe faible). Tout le reste devient « Un problème est survenu. Réessayez dans un instant. »

    Action principale : réessayer → même action

    Si la cause est inconnue → aucune piste ni référence de support pour le client, ni pour nous.
  2. 2Actions destructrices

    12 fenêtres de confirmation (supprimer, archiver, retirer un membre, tout effacer…). Pas d'annulation après coup.

    Action principale : Confirmer → action exécutée

  3. 3Accès fermé (fin d'essai)

    Écran dédié : cause, « vos données sont conservées », actions Vérifier à nouveau / Se déconnecter.

    Action principale : Vérifier à nouveau → retour à l'app si l'accès est rouvert

Priorités recommandées

  1. Liste « Premiers pas » pour le propriétaire sur l'accueil : ajouter le logo, une voiture, un client, créer une première location. Chaque ligne ouvre directement le bon écran ; elle disparaît quand tout est fait. (flow-onboarding)
  2. Messages d'erreur utiles : reconnaître l'échec d'envoi d'e-mail et les autres erreurs de connexion, et ajouter une petite référence « Code : XXXX » pour le support. (flow-errors)
  3. Rendre le Chat M3ak et les Contrats faciles à trouver sur mobile. (flow-navigation)
  4. Récapitulatif avec liens « Modifier » et « (facultatif) » dans les libellés. (flow-forms)
  5. Accessibilité des champs (étiquettes, erreurs reliées) et conservation de la position en changeant d'onglet. (flow-forms, flow-navigation)

Questions ouvertes et points à vérifier

  • Moment d'activation : confirmez-vous « première location créée » comme objectif du démarrage ?
  • Permission des notifications au premier lancement : à vérifier sur un vrai téléphone.
  • Aucun chiffre d'usage n'existe encore : ni taux d'abandon par écran, ni temps jusqu'à la première location. À mesurer avec le premier client.
  • Écrans non audités ici : maintenance, équipe, filiales, traçabilité, inspection photo, signature du contrat, paramètres de l'entreprise.

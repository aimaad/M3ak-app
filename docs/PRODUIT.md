**M3ak — La plateforme intelligente pour gérer votre activité de location automobile**

M3ak est une application mobile tout-en-un conçue pour les agences de location de voitures. Elle regroupe dans une seule plateforme toutes les fonctionnalités dont un employé, un responsable de flotte ou un manager a besoin au quotidien pour gérer efficacement son activité.

L’application permet de gérer l’ensemble de la flotte automobile, les disponibilités, les réservations, les locations, les clients, les véhicules, la maintenance, les paiements, les factures, les agences et les performances de l’entreprise. L’objectif est simple : centraliser toutes les opérations dans une seule application et permettre aux équipes de travailler plus rapidement, avec une meilleure visibilité sur leur activité.

### Une gestion complète de la flotte

Depuis l’application, l’employé peut consulter l’état de chaque véhicule et savoir instantanément s’il est disponible, en location, en maintenance ou en attente d’inspection.

Il peut également accéder à l’historique de chaque véhicule, consulter son kilométrage, ses locations précédentes, ses inspections, ses incidents, ses revenus générés et ses opérations de maintenance.

### 🔥 Inspection intelligente par caméra — la fonctionnalité phare

M3ak intègre une technologie d’**Inspection intelligente par caméra basée sur l’intelligence artificielle**.

Lorsqu’un véhicule revient d’une location, l’employé peut simplement utiliser la caméra de son smartphone pour inspecter le véhicule. L’IA analyse automatiquement les différentes parties de la voiture afin d’identifier les éventuels dommages : rayures, impacts, dommages sur la carrosserie, roues, pare-chocs, etc.

L’IA compare également les inspections précédentes avec la nouvelle inspection afin d’identifier les **nouveaux dommages apparus pendant la location**.

L’employé obtient ensuite immédiatement les informations importantes :

* dommages détectés ;
* localisation du dommage ;
* niveau de gravité ;
* niveau de confiance de la détection ;
* comparaison avant / après ;
* historique des inspections.

Un rapport d’inspection peut ensuite être généré automatiquement et partagé ou envoyé au client.

L'objectif est de remplacer une inspection manuelle longue et subjective par une inspection **rapide, structurée et assistée par l'IA**.

### 🤖 Un assistant IA qui connaît toute votre activité

M3ak intègre également un **assistant IA conversationnel intelligent**, accessible directement depuis l'application.

L'employé peut lui poser des questions en langage naturel et obtenir rapidement des réponses basées sur les données de l'entreprise.

Par exemple :

> « شكون كرا هاد الطوموبيل ملي وقع هاد الضرر؟ »

L'assistant peut rechercher dans l'historique des locations et des inspections pour identifier la location concernée et les informations disponibles sur le véhicule et le client.

L'employé peut également demander :

> « Pourquoi la voiture X génère moins de revenus que les autres ? »

L'IA peut analyser les données disponibles : nombre de jours loués, périodes d'immobilisation, prix moyens de location, fréquence des locations et autres indicateurs pertinents, puis présenter les éléments qui expliquent cette différence.

Il peut aussi demander :

> « Quand est-ce que je dois faire la vidange de la voiture X ? »

L'assistant consulte les informations disponibles sur le véhicule, son kilométrage, son historique de maintenance et les échéances enregistrées afin de fournir une réponse rapide.

L'objectif est de permettre à l'employé de **poser une question au lieu de chercher manuellement l'information dans plusieurs écrans**.

### 📊 Un copilote pour le manager

L'IA ne sert pas uniquement à répondre aux questions. Elle peut également aider le manager à comprendre son activité.

Elle peut mettre en évidence :

* les véhicules les plus rentables ;
* les véhicules sous-utilisés ;
* les véhicules qui nécessitent une maintenance ;
* les périodes de forte ou faible demande ;
* les tendances des réservations ;
* les performances de la flotte ;
* les anomalies ou situations nécessitant une attention particulière.

Le manager dispose ainsi d'une vision plus claire de son activité et peut prendre ses décisions à partir des données disponibles.

### L'idée centrale

M3ak n'est pas simplement une application pour enregistrer des locations.

C'est un **véritable assistant intelligent pour l'agence de location** : il centralise les opérations, automatise les tâches répétitives, analyse les véhicules grâce à la caméra et permet aux employés de poser directement leurs questions à l'IA.

**Une seule application pour gérer la flotte, comprendre son activité et travailler plus intelligemment.**
